### ⚡ Engineering Manifesto

> *"High-level AI abstractions are convenient, but true engineering mastery lies in understanding the silicon beneath them. I don't just consume pre-built frameworks — I build the high-speed engines that power them."*

I am a Computer Science student and systems-level AI engineer dedicated to bridging the chasm between **Deep Learning algorithms** and **Bare-Metal Hardware Efficiency**. My work revolves around modern **C++ (C++20/C++23)**, **CUDA GPU acceleration**, and **SIMD vectorization (AVX2/AVX-512)** to eliminate abstraction penalties and achieve maximum FLOPS throughput.

- 🔬 **Research Interests**: Neural Network Architecture, GPU Kernel Fusion, Low-Bit Quantization (INT4/INT8), Zero-Copy Inference Engines.
- ⚙️ **Systems Focus**: Cache Locality, Memory-Bound vs Compute-Bound Optimization, Lock-Free Concurrency, SIMD Matrix Computation.
- 🎯 **Current Mission**: Developing a modular C++ Deep Learning inference runtime with zero external dependencies and custom CUDA kernels.
